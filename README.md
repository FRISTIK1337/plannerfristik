# fristik.planner — GitHub Pages build

Это статическая версия сайта: без сборщика, Node.js, npm и серверной части.

## Файлы
- `index.html` — разметка сайта
- `style.css` — оформление
- `app.js` — логика расписания, статистики, коллекции, магазина и кейсов
- `assets/images/` — локальные изображения и иллюстрации

## Публикация на GitHub Pages
1. Распакуй архив.
2. Загрузи **все содержимое** папки в корень репозитория (важно: `index.html`, `style.css`, `app.js` и папка `assets` должны лежать рядом).
3. В GitHub открой `Settings → Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем сохрани.
5. Открой адрес GitHub Pages после завершения публикации.

Не переименовывай `assets` и не перемещай файлы по отдельности: все ссылки в проекте относительные и рассчитаны на размещение в корне сайта или в корне проекта GitHub Pages.

## Локальный запуск
Открой `index.html` в браузере. Для GitHub Pages никаких дополнительных шагов сборки не требуется.

## Данные
Прогресс хранится в `localStorage` текущего браузера. Перед заменой старой версии экспортируй резервную копию внутри планера. После публикации новой версии открой сайт в том же браузере и, если потребуется, импортируй резервную копию.
